# 污点分析集成设计方案

## 🤔 您的设计："每轮登录后启动污点分析"

### 方案概述
```
Round 1: 输入密码 → 登录成功 → 启动污点分析 → 追踪Cookie存储
Round 2: 输入密码 → 登录成功 → 启动污点分析 → 追踪Cookie存储
...
```

---

## ✅ 方案评估

### 优点
1. ✅ **精确追踪** - 知道每轮使用的具体密码
2. ✅ **上下文清晰** - 每轮的污点流独立分析
3. ✅ **易于调试** - 可以单独查看某轮的问题

### 潜在问题
1. ⚠️ **重复启动开销** - 每轮都要加载Frida脚本
2. ⚠️ **时机问题** - 登录成功后Cookie可能已经存储了
3. ⚠️ **遗漏早期流** - 密码输入到登录之间的流可能错过

---

## 💡 改进方案：全局启动 + 轮次标记

### 推荐设计

```
测试开始: 
    ↓
启动污点分析（一次性）
    ↓
Round 1: 
    标记密码为污点 → 输入 → 登录 → 检测流 → 记录结果
    ↓
Round 2:
    标记密码为污点 → 输入 → 登录 → 检测流 → 记录结果
    ↓
测试结束:
    ↓
生成综合报告
```

### 优势对比

| 特性 | 每轮启动 | 全局启动（推荐） |
|------|---------|-----------------|
| **性能** | ⚠️ 开销大 | ✅ 只启动一次 |
| **完整性** | ⚠️ 可能遗漏 | ✅ 捕获所有流 |
| **轮次区分** | ✅ 天然隔离 | ✅ 通过标记区分 |
| **密码追踪** | ✅ 明确 | ✅ 标记即可 |

---

## 🎯 最终推荐：混合方案

结合两种方案的优点：

```
1. 测试开始时启动污点分析（全局）
2. 每轮开始时标记当前轮的密码
3. 每轮结束时提取该轮的污点流
4. 测试结束时生成完整报告
```

### 具体流程

```
┌─────────────────────────────────────────────────────────────┐
│  测试初始化阶段                                              │
│  - 启动应用                                                  │
│  - 启动Frida污点分析（一次性）                               │
└─────────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────────┐
│  Round 1                                                     │
│  1. 标记: TaintDB.markRound(1, password="test123")          │
│  2. 输入: UI自动化输入密码                                   │
│  3. 登录: 点击登录按钮                                       │
│  4. 检测: Frida自动追踪污点流                               │
│  5. 提取: getTaintFlowsForRound(1)                          │
│  6. 报告: 记录Round 1的违规                                  │
└─────────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────────┐
│  Round 2                                                     │
│  1. 标记: TaintDB.markRound(2, password="test456")          │
│  2-6. 同上...                                                │
└─────────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────────┐
│  测试结束                                                    │
│  - 生成综合报告（所有轮次）                                  │
│  - 统计分析                                                  │
└─────────────────────────────────────────────────────────────┘
```

---

## 📝 核心优势

1. **一次启动，全程监控** - 避免重复开销
2. **轮次隔离** - 可以区分每轮的污点流
3. **完整捕获** - 从密码输入到存储的完整路径
4. **灵活报告** - 可以单轮分析，也可以综合分析
